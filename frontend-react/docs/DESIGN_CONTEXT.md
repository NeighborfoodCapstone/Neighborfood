# Neighborfood React 공통 디자인 기준

기준: 사용자가 승인한 2026-09-20 메인 화면 v2. HTML 시안을 새로 만들지 않고 실제 React 화면에 적용한다.

## 적용 방식

- 기존 메인 HomePage의 정보 배치와 AppLayout의 헤더·본문·하단 메뉴 구성을 유지한다.
- 나머지 페이지는 TSX로 구현하고 React 상태·이벤트로 동작시킨다. iframe, HTML 문자열 주입, 기존 script 실행 래퍼로 대체하지 않는다.
- API와 DB는 기존 FastAPI를 사용한다. 요청·오류·인증 처리는 migration/core.tsx에서 공유한다.
- 각 페이지는 migration/design.css의 공통 토큰·폼·버튼·리스트·대화상자 스타일을 사용한다.
- 초록색을 배경·가격·배지에 반복 적용하지 않는다. 지도, 카메라, 사진 및 오류 의미색은 별도다.
- 홍보 문구, 가짜 추천, 가짜 통계, 작동하지 않는 버튼은 추가하지 않는다.
- 메인에서 제거한 두 홍보 문구는 다시 넣지 않는다.
- 페이지의 필수 입력·행동·정보 순서를 유지하는 것을 기준으로 한다. 기존 HTML과 픽셀 단위 동일성은 아직 검증하지 않았다. React 전환 중 묶인 화면과 기존 API의 제약은 MIGRATION_REPORT.md에 기록한다.

## 유지할 상태

모든 조회 화면은 로딩·빈 목록·실패·재시도를 구분한다. 전송 중 중복 클릭을 막는다. 401과 403을 구분하고, 관리자 기능은 실제 서버 권한 검사도 받는다. QR 카메라는 화면을 떠나면 스트림을 종료한다. GPS 인증 결과를 클라이언트 추정으로 성공 처리하지 않는다.

## 공통 로딩·자동완성·게시글 상세 보강

- 화면 전환과 최초 데이터 요청은 공통 로딩을 사용한다. 임의로 대기 시간을 늘리지 않으며, 채팅 갱신 등 백그라운드 재조회는 기존 내용을 유지한다.
- 검색·회원 검색·주소 검색은 공통 Autocomplete를 사용한다. 입력창의 기존 폭을 유지하고 목록은 해당 입력창 폭을 따른다. 흰 배경, 회색 경계선·선택 상태, 8px 모서리와 짧은 등장 효과를 공유한다.
- 250ms 디바운스, 최대 8개 제안, 이전 요청 취소, 한글 조합 중 요청 방지, 방향키·Enter·Escape 조작을 지원한다. 로딩·빈 결과·실패를 구분한다.
- 게시글 상세만 데스크톱 콘텐츠 최대 폭을 1320px로 넓힌다. 큰 사진·작성자 영역과 제목·가격·설명·거래 행동을 2열로 표시하고, 900px 이하에서는 1열로 배치한다. 다른 화면의 폭은 유지한다.
- 실제 사진·서버 정보를 사용하고 없는 이미지나 정보를 임의로 생성하지 않는다.
- 실제 브라우저의 시각 검증은 미완료이며 빌드와 DOM 상호작용 검사로 검증한 상태다.
