# 관리자 체험 모드 (전시 부스용)

관리자가 부스 방문자(체험자)에게 **더미 거래**를 배정하면, 체험자는 자기 폰에서
`채팅 → 일시 확정 → 위치·QR 인증 → (정산) → 후기` 흐름을 직접 체험합니다.
가상 참여자(`demo_nb_1`, `demo_nb_2`)의 조작은 부스 노트북의 **관리자 > 체험 모드** 화면에서 합니다.

## 준비
1. 체험자가 폰으로 앱에 **직접 회원가입**합니다. (로그인 ID를 기억)
2. 부스 노트북에서 관리자 계정으로 로그인합니다. (필요 시 `py seed_admin.py promote`, 끝나면 `py seed_admin.py revoke`)
3. **폰 카메라 QR 스캔은 HTTPS가 필요**하므로 노트북·폰 모두 배포(Vercel) 주소를 사용합니다. 이 기능이 배포돼 있어야 합니다.

## 진행 순서
| 단계 | 누가 | 화면/동작 |
|---|---|---|
| 1 | 관리자(노트북) | 관리자 > **체험 모드** > 체험자 ID 선택 → 거래 유형(랜덤/공동구매/나눔/교환) → **더미 거래 생성** |
| 2 | 체험자(폰) | 채팅 목록에서 방 입장(체험자 = 주최자/제공자). 가상 이웃의 메시지가 있음 |
| 3 | 체험자(폰) | 일시만 정함 — 공동구매: 채팅방 "거래 진행" → **약속 정하기** / 나눔·교환: **내 활동** → 거래 카드 → **약속 장소·일시 설정**. 장소는 서일대 호천관으로 서버가 고정 |
| 4 | 체험자(폰) | 공동구매: **정산 시작하기** → 총액 입력 / 나눔·교환: 내 거래 화면 |
| 5 | 관리자(노트북) | 참여자 옆 **위치 인증 + QR 발급** → 위치가 호천관 고정 좌표로 인증되고 QR 표시 |
| 6 | 체험자(폰) | 공동구매: 채팅방 "거래 진행"의 **참여자 QR 스캔**(`settlementId`) / 나눔·교환: 내 활동 거래 카드의 **신청자의 QR 스캔**(`transactionId`) → 노트북 QR 읽기. 경로가 다르면 인증 실패 |
| 7 | 관리자(노트북) | 공동구매만: **납부 처리** (참여자마다 5→6→7 반복) |
| 8 | 체험자(폰) | 공동구매: **정산 완료** → 후기 / 나눔·교환: 스캔 즉시 거래 완료 → 후기 |
| 끝 | 관리자 | **이 체험자 거래 초기화** (두 번 클릭) — 거래·채팅·후기 삭제, 신뢰 온도 36.5 복원 |

QR 유효시간은 5분이며(위치 증거 유효시간과 동일), 지나면 다시 발급하면 됩니다.

주의: 공동구매에서 체험자가 **약속을 다시 저장하면 모든 참여자의 위치·QR 인증이 초기화**됩니다(기존 정산 규칙). 인증을 시작한 뒤에는 약속을 바꾸지 마세요. 참여자 옆 **불참 처리**는 노쇼로 기록되니 누르지 마세요.

### 거래 유형별 입구
| | 공동구매 | 나눔·교환 |
|---|---|---|
| 채팅 | 단체 채팅 | 1:1 채팅 |
| 인증 단위 | 정산(참여자마다) | 거래 1건 |
| 납부·완료 | 관리자 납부 처리 → 체험자 정산 완료 | QR 스캔 즉시 거래 완료 |

## 안전장치
- `/api/admin/demo/*` 는 관리자만 호출 가능. 대상은 활성 일반 회원이며 관리자·가상 이웃은 거부.
- 제목이 `[체험] `으로 시작하는 해당 회원의 게시글(과 연결 데이터)만 만들고 지웁니다. 체험자당 최대 5건.
- 기존 GPS·QR·정산 검증 코드는 수정하지 않았습니다. QR 스캔은 실제 `/api/qr/verify` 가 체험자 폰에서 수행합니다.
- 체험 게시글에 한해 약속 장소 저장 시 서버가 호천관 주소·좌표로 덮어씁니다(일시만 변경 가능).
- 주의: 초기화는 체험자의 신뢰 온도를 36.5로 되돌립니다. 부스 전용 계정에만 쓰세요.

## 호천관 좌표
`app/core/demo_spot.py` 의 `SPOT_LAT / SPOT_LNG` (기본 37.5890, 127.0940 — **근사값**).
관리자 화면의 "지도로 확인" 링크로 위치를 확인하고, 다르면 환경변수 `DEMO_SPOT_LAT`, `DEMO_SPOT_LNG` 로 덮어쓰세요.

## API (모두 관리자 전용)
- `GET  /api/admin/demo/users?q=` 체험자 검색
- `GET  /api/admin/demo/trades?loginId=` 체험 거래·참여자별 진행 상태
- `POST /api/admin/demo/trades` `{loginId, type: random|groupbuy|share|exchange}`
- `POST /api/admin/demo/trades/{postId}/participants/{userId}/qr` 위치 인증(고정) + QR 발급
- `GET  /api/admin/demo/qr/{sessionId}` QR 스캔 여부(폴링)
- `POST /api/admin/demo/settlements/{id}/participants/{userId}/pay` 납부 처리(QR 스캔 후에만)
- `DELETE /api/admin/demo/trades?loginId=` 초기화
