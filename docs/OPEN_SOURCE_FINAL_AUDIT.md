## 세부 결과

### 비밀정보 및 개인정보

- Gitleaks 8.30.1 공식 배포본의 SHA-256을 검증하고 마스킹 옵션으로 로컬 전체 참조에서 도달하는 84개 커밋을 검사했습니다. 범위는 검사 당시 로컬 참조이며, 도달 불가능한 객체나 다른 사람의 클론·GitHub의 모든 숨은 캐시까지 검증한 것은 아닙니다.
- 과거 카카오 키 탐지 4건은 오래된 로컬 전용 이력의 frontend/Group_Buy_Detail.html 및 frontend/Product_Detail.html에서 확인됐습니다. 이 탐지 커밋은 확인한 main과 전환 브랜치의 조상이 아닙니다. 사용자에 따르면 해당 키는 무효화됐으며 콘솔에서 독립 확인하지 않았습니다.
- 옛 공개 커밋 f3f6387은 감사 당시 GitHub API에서 직접 접근 가능했습니다. 오래된 로컬 백업 브랜치와 삭제된 원격 기능 브랜치의 로컬 추적 참조도 이전 이력을 보유합니다. 사용자의 앞선 판단에 따라 해당 참조나 GitHub 캐시는 추가 삭제하지 않았습니다.
- tests/test_ocr_guard.py:54의 탐지는 테스트용 값으로 판별했습니다.
- 로컬 .env:5의 SUPABASE_SECRET_KEY 항목이 탐지됐습니다. .env는 Git 무시 대상이며 현재 추적되지 않습니다. 실제 값은 출력하지 않았고, 정확한 값과 일치하는 파일은 전체 로컬 참조에서 도달하는 767개 Git blob 중 0개였습니다. 값의 유효성이나 Git 밖 유출 여부는 확인하지 않았습니다. 파일이나 값을 삭제하지 않았습니다.
- 현재 문서의 PC 계정명과 팀원 실명 후보는 일반 표기로 대체했습니다. 이전 Git 이력과 외부 복사본에는 과거 표기가 남을 수 있습니다. 화면 캡처 74장의 OCR 패턴 검사 결과는 개인정보 부재의 증명이 아닙니다.

### 라이선스와 배포

- frontend-react/package-lock.json은 PortOne 브라우저 SDK 0.1.12를 잠급니다. 공식 배포본은 MIT 또는 Apache-2.0을 표시하며 프로젝트는 MIT 원문과 저작권 고지를 보존합니다. 기존 0.1.11과 0.1.12의 실행 코드와 타입 파일은 바이트 단위로 일치했습니다.
- frontend-react/public/THIRD_PARTY_NOTICES.txt는 브라우저 JS 시험 빌드에 포함된 7개 패키지의 고지를 모읍니다. 격리 빌드에서 파일과 HTML 링크를 확인했습니다. 직접 접근 시에는 Vercel 인증 화면으로 이동했으나, 이후 사용자가 미리보기 결과로 제공한 텍스트는 저장소 고지 원문과 끝 줄바꿈을 제외하고 일치했습니다(2026-11-15). 사용자 제공 결과이며 실제 응답 URL을 독립 검증한 것은 아닙니다.
- Windows x64 / Python 3.14 격리 설치 예시에서 psycopg 및 psycopg-binary는 LGPL-3.0-only, certifi는 MPL-2.0으로 표시됐습니다. 요구사항의 일부 버전은 고정되지 않아 이 예시는 실제 운영 환경과 다를 수 있습니다. 플랫폼별 내장 바이너리와 재배포 조건은 실제 배포물 기준 추가 확인이 필요합니다.
- 이미지·아이콘 및 QR에 대해서는 현재까지 확인한 자료로 충분하다는 팀의 중론을 사용자에게서 전달받았습니다. QR 번들의 전체 대응 소스와 Classpath 예외 적용 범위가 독립 법률 검토로 확정된 것은 아닙니다. 관련 원문과 불확실성은 THIRD_PARTY_NOTICES.md에 남겼습니다.
- 자세한 구성 목록과 라이선스 원문은 docs/DEPENDENCY_LICENSE_AUDIT.md 및 third_party_licenses/를 참고하세요.

### 문서와 PR

- 주요 문서 7개의 로컬 링크 37개에서 누락은 없었습니다. GitHub 비공개 취약점 제보 기능은 활성화돼 있습니다. 기여자 MIT 전환 동의는 사용자 보고이며 팀원별 독립 확인은 하지 않았습니다.
- PR #1은 검사 당시 Draft/open이었고, GitHub API는 mergeable=true와 Vercel 프런트·API success를 반환했습니다. Supabase Preview는 skipped였습니다. 새 커밋이 추가되면 최신 head의 상태를 다시 확인해야 합니다.
- PR 설명은 현재 팀원 동의와 키 처리 등의 이전 체크리스트를 유지합니다. 이를 최신 내용으로 교체하려 했으나 연결된 GitHub 앱이 PR 및 이슈 편집을 모두 HTTP 403으로 거부해 변경하지 못했습니다.
